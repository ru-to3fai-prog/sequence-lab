# 数列の公式 ― 式の書き方

高校数学Bの4教材をまとめた、HTMLだけで動く教材集です。

- 等差数列の一般項
- 等差数列の和（問題で与えられた条件に応じて公式を表示。選択ボタンなし）
- 等比数列の一般項
- 等比数列の和（r−1の公式を基本、公比1にも対応）

## 使い方

`index.html` をブラウザで開きます。公式→代入→解説→答えを順に表示し、正誤の2択に回答します。初項・公差・公比・項数を変えた問題をシャッフルして出題します。

オンライン時のみCDNからMathJax 3を読み込みます。オフライン時はHTMLの分数・指数・添字で表示します。画像や入力キーボードは使用しません。

## GitHub Pages

このフォルダーの**中身**をリポジトリのルートにアップロードしてください。`index.html` がルート直下に来る配置です。

リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選び、main ブランチの / (root) を指定します。

## ファイル

すべての教材HTMLは単独でも動きます。相互リンクを使うには同じフォルダーに置いてください。ビルド・npm・サーバーは不要です。
